This is the project towards the work of utilizing topic modeling for music recommenddations.
To run the demo recommendation pipeline, first install a python virtual environment (using python 3.11 in this repository). I recommend using uv - a lightweight, fast, efficient python and its packages managers
Then, install the necessary dependencies by uv sync.
Next, go to the Experiments folder and run the notebooks to generate the models. Finally, a clean recommendation pipeline can be demonstrated by running run.py in the "ctm" and the "lda" folder.
